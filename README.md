# Cypher Events
### Android Event Registration & Lottery Management Platform

Cypher Events is an Android-based event management platform designed to streamline registration for high-demand events through a fair lottery-based selection system.

The application enables organizers to create and manage events, monitor waiting lists, send invitations, and track attendee responses, while participants can browse events, scan QR codes, join lotteries, and receive real-time updates.

Built as part of a collaborative software engineering project at the University of Alberta, the system emphasizes accessibility, scalability, and user-focused mobile design.

## Running the Project

### Prerequisites
- Android Studio installed
- Android emulator or physical Android device

### Firebase Configuration

Download the Firebase configuration file from the link below and place it in:

```bash
app/google-services.json
```

[Download google-services.json](https://drive.google.com/file/d/1-ztT4kKQxFihKGCTTafSvvB78TkCu-hz/view?usp=sharing)

### Setup Instructions

1. Clone the repository

```bash
git clone <repository-url>
```

2. Open the project in Android Studio

3. Sync Gradle dependencies

4. Run the application on an emulator or Android device
